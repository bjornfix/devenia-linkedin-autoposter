# Devenia Autoposter for LinkedIn

Automatically share WordPress posts to LinkedIn using the official LinkedIn API. Supports personal profiles, company pages, or both.

## Canonical plugin

This GitHub repository is a lightweight landing page only.

The plugin source, releases, downloads, and support live on WordPress.org:

- Plugin page: https://wordpress.org/plugins/devenia-autoposter-for-linkedin/
- Support: https://wordpress.org/support/plugin/devenia-autoposter-for-linkedin/
- Source: https://plugins.svn.wordpress.org/devenia-autoposter-for-linkedin/

Please install and update the plugin through WordPress.org or the WordPress admin plugin directory.
